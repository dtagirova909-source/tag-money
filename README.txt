TAG MONEY — первая версия для iPhone

Функции:
- добавление доходов и расходов в рублях;
- автоматический баланс;
- последние операции и история;
- цель накопления;
- локальное сохранение данных в браузере;
- установка на экран Домой после публикации по HTTPS.

Запуск:
1. Распакуй архив.
2. Загрузи все файлы в новый GitHub-репозиторий.
3. В Settings → Pages выбери Deploy from a branch, ветку main и папку /(root).
4. Открой выданный HTTPS-адрес в Safari на iPhone.
5. Нажми Поделиться → На экран Домой.

Важно: это прототип. Записи хранятся локально в браузере этого устройства; синхронизации между устройствами и подключения к банкам нет. Не вводи банковские пароли, номера карт или коды.
